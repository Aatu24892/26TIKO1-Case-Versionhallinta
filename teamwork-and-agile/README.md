# Harjoitustyö: ICT-kurssin case 1

## Aihe: Moderni tiimityö ja ketterät menetelmät
Kansio sisältää artikkelit aiheista
- Agiilisuus, Scrum ja Kanban (ketterat-menetelmat.md)
- Kommunikaatio (Slack, Jira, Teams) (viestintatyokalut.md)
- Git ja Code Review tiimin tukena (versionhallinta-tiimissa.md)
- Psykologinen turvallisuus ja palaute (tiimidynamiikka.md)

## Ohjeita tiimille

### Kirjoitusohjeita

- Artikkelit kirjoitetaan suomeksi
- Ei tarvitse noudattaa 80 merkin rajaa rivillä
- Tiedostonimet formaatissa <tama-on-tiedosto.md>

### Ohjeita ja aikataulu vertaisarviointiin ja kommentointiin

- Lue ja kommentoi vähintään työparin dokumenttia
- Tee kommentointi ennen viikonloppua, jotta muut ehtivät lukea kommentit ja muokata dokumenttia
- Käytä kommentoinnissa omia nimikirjaimia (kommentti)
- Käytä VSCoden kommentointia (Ctrl+') (tai edit-valikosta)
- Commit-viestiksi "tiedosto-nimi.md: add comments"
- Lue oma, muiden kommentoima dokumentti viikonlopun aikana, tee haluamasi muutokset (ei tarvitse poistaa kommentteja)
